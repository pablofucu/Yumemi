# Yumemi

App Android (Kotlin + Jetpack Compose) para hablar con un agente [Hermes](https://hermes-agent.nousresearch.com/) a través de su API server: varios hilos de conversación, respuestas en streaming y vista detallada del razonamiento y de las acciones del agente, con Yumemi cambiando de expresión según lo que hace.

- Conectar el servidor: [docs/conectar_hermes.md](docs/conectar_hermes.md)
- Notas de la API de Hermes: [docs/hermes_api_notes.md](docs/hermes_api_notes.md)
- APK de depuración: pestaña **Actions** → último build → artefacto `yumemi-debug-apk`.

Los sprites de Yumemi pertenecen a planetarian HD (Key / VisualArt's) y se usan aquí sin fines comerciales.
